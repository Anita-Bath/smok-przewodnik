# Smok Przewodnik Mobile

Aplikacja mobilna korzysta z Expo SDK 57, React Native oraz Expo Router.

Pełna instrukcja obejmująca konfigurację API, Supabase, Valhalli, zmiennych
środowiskowych oraz uruchomienie na telefonie i emulatorze znajduje się w
[docs/DEVELOPMENT.md](../docs/DEVELOPMENT.md).

Po przygotowaniu pliku `.env.local` podstawowe polecenia to:

```bash
npm ci
npm start
```
